# YarukotoList

YarukotoList is a simple to-do list application made with Flutter + Hive. I made it following a basic Flutter tutorial from YouTube, before branching off and adding other features such as editing. I also changed the aesthetics to something cleaner and sleek-looking as per my personal preference. Its main purpose is to serve as an exercise to build a strong foundation in the field of Mobile Development and teach me further about the common practices used in coding with Flutter/Dart.
 

UPCOMING FEATURES
- draggable task items
- assign date to tasks
- sort tasks by date
- assign priority levels
